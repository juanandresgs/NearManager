# Near Manager v0.2.1

Near Manager v0.2.1 establishes `near` as the public file-manager command and adds a parameter-free, verified installation path.

## Supported release artifacts

- macOS 13 or later on Apple Silicon (`macos-aarch64`).
- macOS 13 or later on Intel (`macos-x86_64`).
- Current stable Ubuntu-compatible Linux on x86-64 (`linux-x86_64`).
- Current stable Windows on x86-64 with ConPTY support (`windows-x86_64`).

Source builds remain available for other Rust-supported targets, but a successful build does not imply operator qualification.

## User-visible changes

- The primary executable, help and version output, release archive member, and documented command are now `near`.
- The macOS, Linux, and Windows installers require no parameters, detect the supported platform, verify the release checksum, install to a user-local binary directory, and configure the user command path.
- The public README now centers Near Manager's purpose and capabilities and includes an application preview.

## Configuration and plugin migration

No configuration or plugin migration is required. The internal Cargo package and persistent semantic identifiers remain unchanged. Installers accept the v0.2.0 `near-fm` archive member as a compatibility input, install it as `near`, and remove the stale managed `near-fm` executable when upgrading an existing installation.

## Compatibility break

Scripts that invoke `near-fm` must use `near`. The release does not install a `near-fm` alias.

## Known limitations

- Near Manager remains pre-release software. Production qualification is exact-revision and platform-specific.
- Linux and Windows behavior is constrained by native metadata, Trash or Recycle Bin, shell, and terminal capabilities.

## Security and verification

Installers verify the release archive's SHA-256 sidecar before extraction. Release assets include checksums, portable provenance, dependency and license inventories, SPDX SBOMs, and GitHub artifact attestations. See `docs/INSTALL.md` for manual verification.

## Rollback

Restore the v0.2.0 application binaries and any configuration-directory backup. When reinstalling v0.2.0 manually, its primary executable is named `near-fm`.
